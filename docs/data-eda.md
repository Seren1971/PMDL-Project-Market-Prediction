# Разбор данных Hull Tactical

Что лежит в `train.csv` / `test.csv`, откуда это взялось, что в колонках и какие из этого следуют
выводы для модели. Все числа воспроизводятся скриптами `scripts/eda_*.py`, сырой вывод — в `reports/`.

Постановку задачи и метрику см. в [competition-brief.md](competition-brief.md).
Если незнакомы термины (доходность, волатильность, коэффициент Шарпа) — сначала
[data-eda-simple.md](data-eda-simple.md): то же самое, но на пальцах и без жаргона.

## 2. Целевые колонки

Только в train (в test их нет — есть лагированные версии):

| Колонка | Что это |
|---|---|
| `forward_returns` | доходность «купил S&P 500 на закрытии дня `t`, продал на закрытии `t+1`» |
| `risk_free_rate` | дневная ставка ФРС (federal funds rate) |
| `market_forward_excess_returns` | `forward_returns` минус скользящее 5-летнее среднее, винзоризовано по MAD с критерием 4 |

Пропусков в таргетах нет ни одного за все 9048 дней.

**Связь между ними.** Разность `forward_returns − market_forward_excess_returns` — гладкий ряд около
`+0.00046` в день (≈ 10.5 % годовых), меняющийся очень медленно: это и есть вычитаемое скользящее
среднее. Корреляция таргета с `forward_returns` — **0.99994**, то есть по сути это одно и то же с
точностью до медленного сдвига.

Важно: **метрика считается по `forward_returns`, а не по `market_forward_excess_returns`**
(см. код метрики). Excess-таргет — это удобная центрированная мишень для обучения, но бэктест
обязан считаться по `forward_returns` и `risk_free_rate`.

### Ставка

`risk_free_rate` на конце выборки ≈ 0.000146/день ≈ 3.7 % годовых. По декадам средняя ставка:
4.85 % → 2.69 % → 0.55 % → 2.72 %. Это ощутимая величина: при позиции `pos < 1` часть капитала
зарабатывает rf, и в метрике это учитывается явно.

## 4. Главное о таргете: доходности обрезаны

Это самое важное наблюдение обо всём датасете.

```
min(forward_returns) = −3.98 %      max = +4.07 %
эксцесс = 2.2                        (у реального дневного S&P ~10–15)
годовая вола = 16.7 %                (реальная 1990–2025 ~18–19 %)
```

Реальный S&P 500 за этот период имел дни −12.0 % (16.03.2020), −9.0 % (15.10.2008), +11.6 %
(13.10.2008). **В данных таких дней нет вообще.** За 36 лет ни одно движение не вышло за ±4.1 %.

Природа обрезки: экстремальные дни лежат на уровне **≈ 4.3–4.5 скользящих сигм** (окна 60/252/1260
дней дают 4.31 / 4.49 / 4.55). Граница медленно ползёт вверх со временем (0.0395 в начале 1990-х →
0.0407 к 2020-м) — это поведение винзоризации по скользящему робастному разбросу (MAD, критерий 4),
той же процедуры, что описана для excess-таргета, но применённой и к самим `forward_returns`.
Дней, лежащих ровно на локальной границе, — 56 (0.62 %).

Косвенное подтверждение: разность `forward_returns − market_forward_excess_returns`, обычно
идеально гладкая, скачет ровно в дни с |r| > 0.038 (`reports/eda_10_anomaly.txt`) — то есть в дни,
где винзоризация сработала.

### Что из этого следует

1. **Бэктест оптимистичен по хвостовому риску.** Настоящих обвалов в данных нет; стратегия с
   плечом 2 в марте 2020 здесь потеряет заметно меньше, чем потеряла бы в жизни.
2. **Метрика считается по этому же обрезанному ряду** — и на публичной, и на forecasting-фазе.
   Значит для скора это внутренне согласовано, «чинить» ряд не нужно.
3. **Но в forecasting-фазе обрезка задним числом ещё не применена** к последним дням: MAD-окно
   должно быть посчитано, а свежие дни могут прийти менее обрезанными. Позицию 2.0 на входе в
   турбулентность лучше не держать.

### Дефект в данных: `date_id 8990`

```
date_id  forward_returns  market_forward_excess_returns     diff
   8989         0.000099                      −0.000368  0.000467   ← норма
   8990         0.000099                       0.004856 −0.004757   ← аномалия
   8991        −0.001377                      −0.001844  0.000467   ← норма
```

`forward_returns` на 8990 дословно повторяет значение предыдущего дня, тогда как excess-таргет
показывает совсем другое. По excess восстанавливается настоящее значение: ≈ `0.004856 + 0.000467`
= **0.00532**. Единственная такая точка на всю выборку. При обучении — либо чинить по excess, либо
выбрасывать строку; в бэктесте на этом дне не мерить.

## 5. Покрытие фич: чем глубже в историю, тем пусто

Внутри истории фичи дыр нет ни одной: у каждой фичи есть дата старта, после неё ряд непрерывен до
конца. Пропуски — это исключительно «фича ещё не началась».

| Что доступно | С какого `date_id` | Сколько фич полны |
|---|---|---|
| только `D*` | 0 | 9 / 94 |
| ядро (68 фич стартуют разом) | 1006 | 9 / 94 |
| | 2000 | 81 / 94 |
| | 4000 | 86 / 94 |
| | 6000 | 92 / 94 |
| **все 94 фичи** | **7000** | **94 / 94** |

Ключевые точки:

* `date_id < 1006` (~4 года, 1990–1993) — есть **только** 9 дамми и таргеты. Для обучения на фичах
  бесполезно.
* На `date_id = 1006` разом появляются 68 фич — это дата начала проприетарного датасета Hull.
* Поздние старты: `E7` (с 6969, 77 % пропусков), `V10` (6049), `S3` (5733), `M1/M13/M14` (5540),
  `M6` (5043), `V9` (4539).

### Практический выбор окна обучения

| Вариант | Строк | Фич без пропусков | Комментарий |
|---|---|---|---|
| `date_id ≥ 1006` | 8042 | 68 | максимум истории, но 26 фич надо импутировать |
| `date_id ≥ 4000` | 5048 | 86 | компромисс |
| `date_id ≥ 7000` | 2048 | **94** | все фичи, но только ~8 лет — мало для 94 признаков |

Рекомендация: базово учить на `date_id ≥ 1006` с явной маской «фича ещё не существует» (индикатор
+ импутация), а не резать выборку до 2048 строк. Модель на 2048 строках и 94 шумных признаках
переобучится гарантированно.

* `D1 ≡ D2` — **побитово идентичны**, одна из двух лишняя.
* `D6` принимает значения **{−1, 0}**, а не {0, 1}. Единиц там нет вовсе. Знак осмысленный: это

* Остальные — {0, 1}.

Средняя доходность в дни `D=1` против `D=0` (годовых): `D1/D2` +61.6 % против +10.2 %,

* 48 фич из 94 лежат строго в `[0, 1]` — это готовые перцентили / нормированные ранги.
* 19 похожи на z-score (|mean| < 0.3, std в 0.5…2).
* Диапазон std по всем фичам: 0.0025 … 1.99. Масштабы разные, стандартизация нужна.
* Почти-дубликаты: `I5 ~ I9` (corr 0.9999), `V9 ~ V10` (0.984), плюс `D1 ≡ D2`.

## 7. Предсказательная сила фич: доходность — почти шум, волатильность — нет

### Доходность

Корреляция каждой фичи с таргетом того же дня (на `date_id ≥ 7000`, n = 2048):

```
медиана |pearson| по 94 фичам:  0.016
фич с |t| > 2:  11 из 94        (чистый шум дал бы ~5)
фич с |t| > 3:   2 из 94
топ: P10 −0.080, P8 −0.071, V13 +0.056, P2 +0.055, M3 +0.055
```

Сигнал есть, но он на грани различимости. Хуже того — **он нестабилен**: если разбить выборку
пополам, знак IC совпадает лишь у 52 фич из 94 (это уровень подбрасывания монеты), а корреляция
между IC первой и второй половины — всего **0.169**.

Автокорреляция самих доходностей тоже почти нулевая: lag 1 = −0.045, дальше ±0.02.

**Вывод: прямого предсказания дневной доходности из этих фич почти не выжать.** Любая модель,
показывающая на валидации высокий R² по доходности, — переобучена.

### Волатильность

А вот здесь всё иначе. Корреляция фич с будущей реализованной волатильностью (среднее |r| за
следующий 21 день):

```
V7  0.626   V9  0.597   E19 0.584   V10 0.564   M1  0.554
S8 −0.510   V13 0.464   P6  0.444   S3 −0.398   P10 −0.370
фич с |corr| > 0.3: 16 из 94
медиана |corr| с волой: 0.102   против 0.016 с доходностью
```

Плюс сама волатильность кластеризуется: автокорреляция |r| = +0.23 (lag 1), +0.28 (lag 5),
+0.19 (lag 21).

**Это и есть главный рабочий сигнал в датасете.** Волатильность предсказуема на порядок лучше
направления. Метрика — Sharpe со штрафом за волу, то есть у неё в знаменателе стоит ровно то, что
мы умеем прогнозировать. Отсюда естественная архитектура стратегии: **vol-targeting** (размер
позиции обратно пропорционален прогнозу волатильности) как основа, а слабый прогноз направления —
лишь как небольшая надстройка сверху.

## 8. Бенчмарки метрики и уровень шума

Скор константных позиций (`scripts/eda_08_baseline.py`, вся история):

| pos | score | sharpe | vol_ratio | штраф за отставание |
|---|---|---|---|---|
| 0.0 | 0.000 | 0.000 | 0.01 | 1.60 |
| 0.5 | 0.449 | 0.505 | 0.50 | 1.12 |
| **0.8** | **0.471** | 0.480 | 0.80 | 1.02 |
| 1.0 | 0.463 | 0.463 | 1.00 | 1.00 |
| 1.2 | 0.446 | 0.446 | 1.20 | 1.00 |
| 1.5 | 0.324 | 0.421 | 1.50 | 1.00 |
| 2.0 | 0.211 | 0.379 | 2.00 | 1.00 |

Что видно:

* Плечо строго вредит: при `pos > 1.2` включается линейный штраф за волу, а Sharpe не растёт.
* Оптимум среди констант — около **0.8–1.0**, скор ≈ 0.47. Это планка, которую надо бить.
* «Всё в кэш» (`pos = 0`) даёт ровно 0 — метрика не даёт отсидеться.

На последних 180 днях (размер зачётного окна) те же константы дают 1.10–1.13 — но это просто
удачный период, не заслуга стратегии.

### Сколько в метрике шума

Скор тривиальной стратегии `pos ≡ 1.0` по 50 непересекающимся 180-дневным окнам:

```
медиана 0.663   среднее 0.708   std 1.062   min −1.416   max 3.347
доля окон с отрицательным скором: 18 %
```

**std = 1.06 при медиане 0.66.** Одна и та же тривиальная стратегия на разных 180-дневных отрезках
получает скор от −1.4 до +3.3. Зачётное окно в forecasting-фазе — ровно такого размера.

Отсюда два жёстких следствия:
1. Оптимизировать надо **распределение скора по множеству окон**, а не одно число. Улучшение
   «с 0.66 до 0.75» на одном окне статистически неотличимо от нуля.
2. Итоговое место в лидерборде будет в значительной степени лотереей. Задача — максимизировать
   ожидание и не взорваться на хвосте, а не выиграть конкретное окно.

Для масштаба: оракул (`pos = 2` если завтра рынок обгонит rf, иначе 0) на последних 180 днях даёт
скор **10.05**. Это потолок; реалистичная цель — 0.5…0.9 против 0.47 у константы.

## 10. Что делать дальше

1. Ядро стратегии — **прогноз волатильности** (`V*`, `E19`, `M1`, `S8` + реализованная вола по
   `lagged_forward_returns`) и vol-targeting: `pos = clip(target_vol / pred_vol, 0, 2)`.
2. Прогноз направления — сверху и с маленьким весом; ожидать IC ~0.03–0.05, не больше.
3. Средняя экспозиция ≈ 0.9–1.1: там оптимум по метрике и нет штрафов.
4. Валидация: walk-forward, оценка на ≥ 30 непересекающихся 180-дневных окнах, смотреть медиану и
   10-й перцентиль скора.
5. Сравнивать всё с константой `pos = 0.8…1.0` (скор ≈ 0.47). Не бьёт — выбрасывать.
