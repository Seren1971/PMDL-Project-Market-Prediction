# Hull Tactical — Market Prediction

Решение kaggle-соревнования: каждый торговый день предсказать оптимальную долю капитала в S&P 500
(число от 0 до 2) так, чтобы обогнать рынок по риск-скорректированной доходности, не превысив
120% его волатильности.

**Соревнование:** https://www.kaggle.com/competitions/hull-tactical-market-prediction
**Данные:** https://www.kaggle.com/competitions/hull-tactical-market-prediction/data
**Код метрики:** https://www.kaggle.com/code/metric/hull-competition-sharpe
**Demo submission:** https://www.kaggle.com/code/sohier/hull-tactical-market-prediction-demo-submission

> Статус: призовой цикл соревнования закрыт (final submission — 15 декабря 2025), сабмиты возможны
> только как late submission. Проект ведётся как исследовательский: модель оцениваем офлайн
> собственным бэктестом против бенчмарков.

## Что уже выяснено

1. **Направление рынка практически непредсказуемо** из данного набора признаков: медианная
   корреляция признака с завтрашней доходностью 0.016, знак связи устойчив лишь у половины
   признаков.
2. **Волатильность предсказуема хорошо** — корреляция до 0.63 (`V7`, `V9`, `E19`, `M1`). Поскольку
   метрика — это Шарп, где волатильность стоит в знаменателе, основой стратегии должен быть
   vol-targeting, а не прогноз доходности.
3. **Планка — скор 0.47**: столько даёт константная позиция 0.8–1.0 без всякой модели. Всё, что
   ниже, бессмысленно.
4. **Доходности в данных винзоризованы** на ±4%: реальных обвалов (−12% в марте 2020) в выборке нет,
   поэтому бэктест недооценивает хвостовой риск плеча.
5. **Метрика очень шумная**: скор тривиальной стратегии на 180-дневных окнах гуляет от −1.4 до +3.3
   (std ≈ 1.06). Оценивать модель нужно распределением по многим окнам, а не одним числом.

Подробнее с числами — в [docs/data-eda.md](docs/data-eda.md).

## Структура

```
data/raw/                 распакованный архив с Kaggle (в git не коммитится)
  train.csv               9048 дней × 94 признака + 3 таргета, ~1990-01 .. 2025-12
  test.csv                макет тестовой выборки, 10 строк
  kaggle_evaluation/      клиент evaluation API от организаторов
docs/                     наши выводы из данных (см. таблицу выше)
research/                 разбор чужих решений и внешних материалов
scripts/eda_*.py          скрипты разведочного анализа, по одной теме на скрипт
experiments/exp_*.py      проверка гипотез, по одной теме на скрипт
src/backtest.py           бэктестер: скор по окнам, парное сравнение с бенчмарком
src/wf.py                 walk-forward: честная оценка вне выборки
src/data.py               загрузка и антиутечковые примитивы
reports/eda_*.txt         сохранённый вывод этих скриптов
src/metric.py             метрика соревнования, копия один-в-один
```

Карта EDA-скриптов (что где смотреть) — в конце [docs/data-eda.md](docs/data-eda.md).

## Как развернуть

Данные в репозиторий не коммитятся (правила соревнования + размер). Скачать архив со
[страницы данных](https://www.kaggle.com/competitions/hull-tactical-market-prediction/data)
и распаковать:

```bash
unzip hull-tactical-market-prediction.zip -d data/raw
```

Зависимости: Python 3.11+, `pandas`, `numpy`, `scikit-learn`.

```bash
pip install pandas numpy scikit-learn
```

Перезапустить весь разведочный анализ:

```bash
for f in scripts/eda_*.py; do python3 "$f" > "reports/$(basename "$f" .py).txt" 2>&1; done
```
